## 🌟 Overview & Design Highlights

- 💧 **Liquid Glassmorphism Effects**: Translucent frosted glass layers with morphing background fluid orbs, specular sheen reflections, multi-layer blur (), and iridescent borders.

- 🪐 **Interactive 3D Elements & Parallax**: 3D Hardcover Book, Fountain Pen, Glowing Code Laptop, Microchip/AI Neural Node, and 3D Atom with mouse parallax and 3D card tilt physics.

- ✨ **Integrated Interactive Preloader**: Custom animated SVG spinner (Uiverse.io design by Nawsome) with GSSS 52 LNP school branding that fades out smoothly upon initial load.

This website is a modern, responsive, high-performance web portal created for **Government Senior Secondary School 52 LNP**, engineered using the design system specifications, color scheme, typography, and responsive component library from the provided Figma mockups:

1. **Academic Color Palette**:
   - **Primary**: Deep Academic Navy (`#0D47A1` & `#0A2540`)
   - **Secondary**: Trust Blue (`#1565C0`)
   - **Accent**: Golden Amber / Saffron (`#FFB300`)
   - **Eco / Success**: Forest Green (`#2E7D32`)
   - **Neutral**: Soft Slate (`#F5F7FA`) & Crisp White (`#FFFFFF`)

2. **Typography**:
   - *Playfair Display* & *Cinzel* for headings (academic prestige)
   - *Inter* & *Noto Sans Devanagari* for UI & dual-language readability

3. **Key Features**:
   - 🌐 **Instant Bilingual Toggle (English & हिन्दी)** across all UI elements, headings, notices, and streams.
   - 🎓 **Academic Streams Showcase**: Detailed exploration of Science (PCM/PCB), Agriculture (Agronomy/Horticulture), Arts & Humanities, and Vocational IT.
   - 📢 **Live Notice Board with Filters**: Tabbed categories (All, Examinations, Scholarships & Schemes, Govt. Circulars, Sports) with simulated document download.
   - 📝 **Multi-Step Online Admission Application Modal (2026-27)**: Student info, Guardian & Jan Aadhaar details, summary review, and instant application number generator.
   - 🔍 **Instant Global Search Modal**: Fast indexed search across notices, faculty, courses, and government welfare schemes.
   - 🏫 **Campus & Facilities Tour**: ICT Smart Labs, Composite Science Labs, 5000+ Book Library, PM-POSHAN kitchen, sports fields, solar energy backup.
   - 🏛️ **Govt. Schemes & Welfare Portal**: Free school uniforms, free textbooks, Gargi Puraskar, laptop scheme, PM-POSHAN mid-day meals, free cycle distribution.
   - 👥 **Faculty Directory & Leadership Message**: Principal's message and profiles of teaching staff.
   - 🖼️ **Interactive Photo Gallery with Lightbox**: Filterable by campus, science exhibition, sports meet, and cultural fests.
   - 📱 **100% Responsive Design**: Smooth mobile drawer navigation, tablet layouts (768px), and desktop resolution (1440px+).

## 🚀 How to Run Locally

You can launch a local HTTP server directly from the project directory:

```bash
cd /Users/sanjaytakhar/.gemini/antigravity/scratch/gsss-52-lnp-website
python3 -m http.server 8080
```

Then open your browser at:
`http://localhost:8080`
